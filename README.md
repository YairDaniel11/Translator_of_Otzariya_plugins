# מתרגם תוספי אוצריא

תוכנת Windows שמתרגמת תוספי [אוצריא](https://github.com/Sivan22/otzaria) לשפות נוספות.
היא מחלצת את כיתובי הממשק מהתוסף, מתרגמת אותם באמצעות מודל שפה (Claude או Gemini),
מאמתת את התרגום, ואורזת חבילת `.otzplugin` חדשה — מוכנה להתקנה.

**עברית נשארת שפת הבסיס.** התרגום נשמר במילון חיצוני שמפתחותיו הם מחרוזות המקור
בעברית, ומנוע קטן מחליף אותן בזמן ריצה. מחרוזת שאין לה תרגום נשארת בעברית, ולכן
מילון חלקי לעולם אינו "משבש" את התוסף — הוא רק מתרגם את מה שהוגדר.

---

## התקנה

הורידו את `OtzariaPluginTranslator.exe` מ־[Releases](../../releases).

זהו קובץ בודד ועצמאי: **אינו דורש התקנת פייתון** ואינו דורש התקנה כלל.

## שימוש

1. **בחר קובץ תוסף…** — קובץ ה־`.otzplugin` שברצונכם לתרגם.
   (למפתחי תוספים יש גם **או תיקיית מקור…** — התיקייה שמכילה `manifest.json`.)
2. **מנוע** (Claude / Gemini), **שפה**, ו**מפתח API** של הספק שבחרתם.
3. **מה לתרגם** — ממשק בלבד, או ממשק + תוכן. ראו [היקף התרגום](#היקף-התרגום).
4. **מודל** — אפשר להשאיר ריק לבחירה אוטומטית, או ללחוץ **רענן רשימת מודלים** ולבחור.
5. לחצו **תרגם תוסף**. השלבים — חילוץ, תרגום, אימות — רצים ברקע, וההתקדמות מוצגת בלוג.
6. בסוף נשאלת השאלה היחידה שנותרה: **לאיזו גרסת אוצריא לבנות**. בחרו וקבלו את החבילה.

החבילה נוצרת בתיקייה `פלט-תרגום` ליד קובץ התוסף שבחרתם. **קוד המקור שלכם אינו משתנה** —
הבנייה נעשית תמיד על עותק עבודה זמני.

### עריכת תרגומים

הטבלה מציגה כל מחרוזת, את תרגומה, ואת ציוני האימות. **לחיצה כפולה על שורה** פותחת
עריכה. שורות אדומות הן מחרוזות ששתי בדיקות האימות סימנו כחשודות — כדאי לעבור עליהן.

אם בחרתם **עצור לעריכה** בדיאלוג הסיום, תוכלו לתקן בטבלה ואז ללחוץ **בנה חבילה**
(הכפתור מחליף את עצמו) — בלי לתרגם מחדש ובלי לשלם שוב.

## שתי גרסאות החבילה

| | נעול לשפה | לפי שפת אוצריא |
|---|---|---|
| `minAppVersion` | **0.9.96** | **0.9.97** |
| קביעת השפה | קבועה בשפת היעד | לפי שפת הממשק של אוצריא |
| `id` התוסף | `<id>.<lang>only` — מותקן לצד המקורי | זהה למקורי |
| שם התוסף | קבוע בשפת היעד (עד 14 תווים) | כמו המקורי |
| מתי להשתמש | **לבדיקת איכות התרגום עכשיו** | להפצה למשתמשים |

הסיבה להפרדה: השדה `app.language`, שדרכו תוסף יודע מה שפת הממשק של אוצריא, קיים רק
מגרסה 0.9.97. חבילה "נעולה לשפה" אינה תלויה בו ולכן עובדת גם בגרסאות קודמות — וגם
מחוץ לאוצריא, בדפדפן.

> אוצריא אינה תומכת בשם תוסף תלוי־שפה (`name` הוא מחרוזת אחת), ולכן החבילה הנעולה
> מקבלת שם קבוע בשפת היעד. התוכנה מציעה שם בתוך מגבלת 14 התווים, ואפשר לשנותו.

## היקף התרגום

**ממשק בלבד** (ברירת המחדל) — כפתורים, תוויות, הודעות, placeholder־ים. בתוסף
הביוגרפיות: כ־130 מחרוזות. מהיר וזול.

**ממשק + תוכן** — גם תיקיות הנתונים ומשפטים ארוכים. באותו תוסף: כ־9,000 מחרוזות,
כלומר פי שבעים. התוכנה מציגה את המספר ומבקשת אישור לפני שהיא מתחילה, כי זה נמדד
בזמן ובמכסת API.

### מה לא יתורגם, ולמה

שלוש מגבלות אמיתיות, שכדאי להכיר לפני שמדווחים על תקלה:

1. **הממשק של אוצריא עצמה** — הסרגל העליון, שמות תוספים אחרים, שורת המצב. הם אינם
   חלק מהתוסף שלכם, והתוכנה אינה נוגעת בהם.
2. **טקסט שהקוד מרכיב בזמן ריצה.** מנוע התרגום מחליף מחרוזות שלמות, ולכן
   `n + ' ערכים'` אינו מפתח במילון. המקרה של מספר מוביל **כן** מטופל
   (`"3,735 ערכים"` → `"3,735 entries"`), אבל הרכבות מורכבות יותר — למשל טקסט
   שנבנה ממילים נפרדות — יישארו בעברית.
3. **שמות פרטיים ומונחים תורניים** אינם מתורגמים במכוון: מסכתות, חכמים, ספרים.

## איך זה עובד

```
תוסף  →  חילוץ  →  תרגום (LLM)  →  אימות  →  מילון + מנוע  →  אריזה  →  .otzplugin
```

**חילוץ** ([`translator_core.py`](translator_core.py)) — סורק `.html` ו־`.js`, אוסף
טקסט בין תגיות, מחרוזות במירכאות ואטריביוטים גלויים. מסננים אגרסיביים מסירים שברי
קוד, מפות מקלדת, ביטויים רגולריים ומחרוזות ביחס עברית נמוך — בלעדיהם bundle של
מסגרת (Vue/React) מייצר זבל שנשלח לתרגום.

**תרגום** — נשלח באצוות למודל, עם system prompt שמקבע מונחים תורניים
(`מסכת→Tractate`, `סעיף→se'if`) ושומר על placeholder־ים ופיסוק. אצווה שנכשלה
נכנסת ל**סבבי השלמה** באצוות קטנות יותר, ומה שלא הושלם מדווח מפורשות בלוג — כדי
שלא ייווצר תוסף שחצי ממנו בעברית בלי שתדעו.

**אימות** — כל תרגום נבדק בשני כיוונים בלתי תלויים מול Google Translate: התרגום
חזרה לעברית מול המקור, והמקור לאנגלית מול התרגום. מחרוזת מסומנת כחשודה רק אם
**שתי** הבדיקות נמוכות — די בכך שאחת מאשרת, כי מילה בודדת כמו "שמור" עשויה לחזור
כ"להציל" ולהיות נכונה לחלוטין.

**מילון** — נכתב ל־`i18n/<lang>.js` דרך `json.dumps`, כך שגרש, מקף־על ושורה חדשה
מוברחים כראוי.

**מנוע** ([`i18n_runtime.js`](i18n_runtime.js)) — מחליף צמתי טקסט ואטריביוטים לפי
המילון, ו־`MutationObserver` מטפל בתוכן ובאטריביוטים שנוצרים דינמית. מכיוון שרק
מחרוזות שבמילון מוחלפות, תוכן תורני אינו נוגע. אפשר לסמן `data-i18n-skip` על אלמנט
שאין לתרגם.

**אריזה** — נעשית על עותק עבודה, וההזרקה ל־HTML מסומנת בין `otzaria-i18n:start`
ל־`otzaria-i18n:end` כדי שהרצה חוזרת תהיה idempotent. לבסוף החבילה **מושווית
למקור**, והבנייה נכשלת אם קובץ נשמט.

## פיתוח

```bash
python gui.py              # הרצה מקוד המקור (דורש Python 3.10+, tkinter)
python gui.py --selftest   # בדיקה ללא מסך: חילוץ, מילון, אריזה שלמה
```

בנייה מקומית של ה־EXE, בדיוק כמו ב־CI:

```bash
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed \
  --name OtzariaPluginTranslator \
  --add-data "i18n_runtime.js;." \
  --hidden-import tkinter.simpledialog gui.py
```

### מבנה

| קובץ | תפקיד |
|---|---|
| [`gui.py`](gui.py) | הממשק, זרימת העבודה, ו־`--selftest` |
| [`translator_core.py`](translator_core.py) | חילוץ, תרגום, אימות, אריזה |
| [`i18n_runtime.js`](i18n_runtime.js) | מנוע התרגום שמוזרק לתוסף |
| [`i18n-shared/i18n.js`](i18n-shared/i18n.js) | עותק זהה, לשימוש ישיר במפתחי תוספים |

### בנייה אוטומטית

[`.github/workflows/build-release.yml`](.github/workflows/build-release.yml) רץ בכל
דחיפה שנוגעת בקוד: בודק את המילון, בונה EXE, מריץ `--selftest`, מוודא שהחלון נפתח
ואינו קורס, ומפרסם Release בתג `v<VERSION>-build<N>` (ה־VERSION נקרא מ־`gui.py`).

## פתרון תקלות

| מה שרואים | מה זה |
|---|---|
| `HTTP 503: high demand` | הספק עמוס. התוכנה ממתינה ומנסה שוב מעצמה; אם זה נמשך, נסו מודל אחר. |
| `HTTP 404` על מודל | שם המודל אינו זמין למפתח שלכם. **רענן רשימת מודלים** ובחרו מהרשימה. |
| `⚠ N מחרוזות נשארו בלי תרגום` | אצוות שנכשלו גם אחרי סבבי ההשלמה. הן יופיעו בעברית; הריצו שוב או בחרו מודל אחר. |
| `שם החבילה … חורג מ־14 תווים` | אוצריא מגבילה את `name`. קצרו את השם בדיאלוג. |
| `החבילה נבנתה חסרה` | בדיקת השלמות תפסה קובץ שנשמט. זה באג — פתחו issue עם ההודעה. |
| התוסף מציג "אין תוכן" | חבילה שנבנתה בגרסה מוקדמת של הכלי, שהשמיטה את תיקיות הנתונים. בנו מחדש. |
| הממשק נשאר בעברית | בדקו בדפדפן: פתחו את `index.html` מהחבילה, F12 → Console. שגיאה ב־`i18n/<lang>.js` פירושה מילון פגום. |
